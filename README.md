# To-Do Web App

## Description

A simple To-Do Web App that helps users manage daily tasks efficiently.

## Features

* Add new tasks.
* View all tasks.
* Mark tasks as completed.
* Delete tasks.

## Technologies Used

* HTML
* CSS
* JavaScript

## How to Use

1. Enter a task in the input field.
2. Click the Add button.
3. Mark tasks as completed when finished.
4. Delete tasks when no longer needed.
